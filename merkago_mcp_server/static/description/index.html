Pourquoi choisir Claude Connector Odoo ?

Un script fragile ou un bridge externe expose votre base. Ce module intègre MCP dans Odoo, avec des contrôles que vous maîtrisez.

✓  Natif & fiable : endpoints /mcp/sse, /mcp/messages, /mcp/health — aucun serveur bridge à maintenir.

✓  Sécurité entreprise : OAuth 2.1 / PKCE, scopes par modèle, Safe Mode, quotas journaliers, journal d’audit.

✓  Pensé pour Claude : Connectors Claude (MCP distant), Streamable HTTP + SSE classique.

✓  Droits en un clic : Contacts, Ventes/CRM, Stock, Comptabilité. Pour une autre application : Droits (scopes) → Nouveau → choisir le modèle.

✓  Safe Mode : bloque les écritures jusqu’à ce que vous les autorisiez explicitement.

✓  Idéal consultants & PME : Claude comme assistant ERP, sans exposer toute la base.

Le module en images

Quatre écrans réels : assistant Odoo, droits, connecteur Claude.

1. Connecter Claude

Menu Claude Connector → Connecter Claude. Checklist HTTPS, Safe Mode, outils, et l’URL à copier.

2. Droits par application

Contacts, produits, stock, commandes, CRM, factures. Lecture seule tant que vous n’autorisez pas l’écriture.

3. Connecteur dans Claude

Claude → Plug-ins → Ajouter. Nommez le connecteur et collez https://VOTRE-DOMAINE/mcp/sse.

4. Connecteur actif

Le connecteur personnalisé apparaît dans Claude, à côté de vos autres plug-ins.

Installation technique

Community et Enterprise, Odoo 17 à 20, on-premise ou Odoo.sh. Dépendances : Discuss, Contacts, Produits.

1. Copiez le dossier merkago_mcp_server/ dans le chemin addons du serveur, du Docker ou du dépôt Git Odoo.sh.

2. Redémarrez Odoo. Mode développeur → Applications → Mettre à jour la liste des applications.

3. Installez Claude Connector Odoo. Le bouton « Importer un module » ne charge pas le code Python de ce connecteur.

4. Ouvrez Connecter Claude, renseignez l’URL publique HTTPS, activez les packs de droits, copiez /mcp/sse.

5. Dans Claude, ajoutez le connecteur. Laissez Client ID et Secret vides, puis autorisez un utilisateur interne.

6. Contrôle : https://VOTRE-DOMAINE/mcp/health doit répondre status: ok.

Questions fréquentes

Quelle URL mettre dans Claude ?
https://VOTRE-DOMAINE/mcp/sse — HTTPS public obligatoire. Exemple : https://merkago.net/mcp/sse.
Claude peut-il modifier ma base ?
Uniquement si vous désactivez le Safe Mode et autorisez Write/Create sur les scopes. Par défaut, restez en lecture seule.
Compatible Community ?
Oui : Odoo Community & Enterprise 17, 18, 19 et 20. Dépendances : Contacts, Discuss.
OAuth Client ID ?
Recommandé : merkago-claude-desktop. Sinon laissez vide pour Dynamic Client Registration. Client Secret : toujours vide.
