Setup in Claude — Step by step

1) Open Connectors

Claude → Settings → Customize → Connectors → click Add.

2) Add a custom connector

Choose Add custom connector.

3) Enter Name + MCP URL

Name: Merkago
Remote MCP URL: https://YOUR-DOMAIN/mcp/sse

4) OAuth Client ID (optional) then Add

OAuth Client ID: merkago-claude-desktop (or leave empty for dynamic registration).
OAuth Client Secret: leave empty. Click Add and authorize with an internal Odoo user.

5) Choose scopes in Odoo

Merkago MCP → Tokens / Scopes — whitelist models Claude may access (contacts, products…).

6) Create a new scope (example: Products)

Model product.template, Pack Inventory, Read only recommended. Leave Extra Domain empty for products.

Quick test in Claude

Ask Claude to call odoo_list_models, then count product.template with odoo_search_read.
