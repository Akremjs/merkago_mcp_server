INSTALLATION — Claude Connector Odoo (merkago_mcp_server)
=========================================================

1. Dézippez l'archive.
2. Copiez le dossier merkago_mcp_server/ dans le chemin addons Odoo
   (ex. /mnt/extra-addons/ ou le dépôt Git Odoo.sh).
3. Redémarrez Odoo.
4. Mode développeur → Applications → Mettre à jour la liste des applications.
5. Cherchez « Claude Connector » → Installer.

Le bouton Applications → Importer un module ne charge pas le code Python.
Erreur typique : « Aucun enregistrement trouvé pour id externe model_merkago_mcp_* ».

Dépendances : mail, contacts, product (installées avec le module).

Après l'installation
--------------------
Claude Connector → Connecter Claude
  * URL publique HTTPS
  * Checklist (URL, serveur, droits, OAuth)
  * Droits en un clic : Contacts, Ventes/CRM, Stock, Comptabilité
  * Autre application : Droits (scopes) → Nouveau → modèle Odoo
  * Outils : cochez ceux que Claude peut utiliser
  * Copiez l'URL /mcp/sse dans Claude (Client ID et Secret vides)

Vérification : curl https://VOTRE-DOMAINE/mcp/health
