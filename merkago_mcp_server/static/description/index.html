MCP Server — Claude Connector

Connectez Claude (Desktop / Web) à votre Odoo via un serveur MCP natif : OAuth 2.1 + PKCE, scopes par modèle, Safe Mode et journal d’audit. Claude lit (et peut écrire si vous l’autorisez) vos contacts, produits, ventes… directement depuis le chat.

Odoo 17 / 18 / 19 MCP + SSE / Streamable HTTP OAuth 2.1 · PKCE Safe Mode 90 USD · OPL-1

Pourquoi ce module ?

Claude ↔ Odoo Posez des questions métier en langage naturel : « Combien de produits ? », « Liste les clients », « Décris sale.order ».
Sécurité maîtrisée Whitelist de modèles (scopes), Safe Mode, quotas journaliers, audit log.
OAuth moderne Connexion « Sign in with Odoo » depuis Claude, sans coller de token à la main (token Bearer legacy toujours disponible).
Installation simple Module Apps → activer → URL publique → connecteur Claude en 2 minutes.

Fonctionnalités

  • Endpoints /mcp/health, /mcp/sse, /mcp/messages
  • OAuth 2.1 + PKCE + Dynamic Client Registration (+ Client ID statique)
  • Outils MCP : odoo_list_models, odoo_describe_model, odoo_search_read, odoo_read, odoo_create, odoo_write, odoo_company_context
  • Scopes par modèle (lecture / écriture / création / suppression)
  • Safe Mode (bloque create/write tant qu’il est actif)
  • Journal d’audit des appels Claude → Odoo

Prérequis

  • Odoo Community (ou Enterprise) avec le module installé
  • URL publique HTTPS (ex. https://votredomaine.com)
  • dbfilter pointant vers la bonne base si multi-DB
  • Compte Claude avec accès aux Connecteurs
  • Utilisateur Odoo interne (pas un utilisateur portail)

Démarche — brancher Claude sur Odoo

Suivez les étapes ci-dessous. Les captures montrent le parcours Claude (étapes 1 à 4) puis la configuration des droits dans Odoo (étapes 5 et 6).

Étape 1

Ouvrir les Connecteurs Claude

Dans Claude → Paramètres → section Personnaliser → cliquez sur Connecteurs. Puis cliquez sur le bouton Ajouter en haut à droite.

Capture 1 — Accès au menu Connecteurs et bouton Ajouter.

Étape 2

Choisir « Ajouter un connecteur personnalisé »

Dans le menu déroulant Ajouter, sélectionnez Ajouter un connecteur personnalisé (pas « Parcourir les connecteurs »).

Capture 2 — Création d’un connecteur MCP personnalisé.

Étape 3

Renseigner le formulaire du connecteur

Remplissez les champs comme suit :

Nom : Merkago
URL du serveur MCP distant : https://VOTRE-DOMAINE/mcp/sse
ID client OAuth (recommandé) : merkago-claude-desktop — ou laissez vide pour l’inscription dynamique
Secret client OAuth : laisser vide
Attention URL : un seul https:// et des slashs / (jamais \). Exemple correct : https://merkago.net/mcp/sse

Capture 3 — Formulaire Nom + URL MCP distant.

Étape 4

Paramètres avancés OAuth puis Ajouter

Ouvrez Paramètres avancés, collez l’ID client OAuth si besoin, laissez le secret vide, puis cliquez sur Ajouter. Claude ouvre la page Merkago « Autoriser Claude Desktop » : connectez-vous avec votre utilisateur Odoo interne et autorisez.

Capture 4 — ID client OAuth (facultatif) et validation.

✓ Une fois connecté, les outils Merkago apparaissent dans Claude.

Étape 5

Dans Odoo — choisir les scopes du token

Allez dans Merkago MCP → Tokens (ou le token OAuth lié), ouvrez le token Claude, puis ajoutez les Scopes autorisés (ex. Contacts, Produits, Utilisateurs…). Seuls les modèles cochés seront visibles par Claude.

Capture 5 — Whitelist des modèles exposés à Claude.

Étape 6

Créer un nouveau scope (ex. Produits)

Depuis la liste des scopes → Nouveau :

  • Name : Products / Templates
  • Model : product.template
  • Pack : Inventory
  • Perm Read : oui · Write / Create / Unlink : non (recommandé)
  • Extra Domain : vide (sauf filtre métier volontaire)
  • Enregistrer, puis rattacher le scope au token Claude
L’exemple [('customer_rank','>',0)] sert aux contacts clients, pas aux produits.

Capture 6 — Formulaire de création d’un scope modèle.

Test rapide dans Claude

Utilise l’outil Merkago odoo_list_models (pas ta mémoire), puis compte les product.template avec odoo_search_read.

Paramètres Odoo recommandés

  • Merkago MCP → Settings : Public Base URL = votre HTTPS
  • Safe Mode : ON en production jusqu’à validation
  • OAuth Clients : client statique merkago-claude-desktop avec redirect https://claude.ai/api/mcp/auth_callback
