Pourquoi choisir Claude Connector Odoo ?

Un script fragile ou un bridge externe expose votre base. Ce module intègre MCP dans Odoo, avec des contrôles que vous maîtrisez.

✓  Natif & fiable : endpoints /mcp/sse, /mcp/messages, /mcp/health — aucun serveur bridge à maintenir.

✓  Sécurité entreprise : OAuth 2.1 / PKCE, scopes par modèle, Safe Mode, quotas journaliers, journal d’audit.

✓  Pensé pour Claude : Connectors Claude (MCP distant), Streamable HTTP + SSE classique.

✓  Whitelist stricte : seuls les modèles autorisés (Contacts, Produits, Ventes…) sont visibles.

✓  Safe Mode : bloque les écritures jusqu’à ce que vous les autorisiez explicitement.

✓  Idéal consultants & PME : Claude comme assistant ERP, sans exposer toute la base.

Étape 1 — Claude Connectors

Dans Claude : Settings → Customize → Connectors, puis cliquez sur Add.

Menu Connectors + bouton Add

Étape 2 — Add custom connector

Choisissez Add custom connector (ne pas utiliser « Browse connectors »).

Ajout d’un connecteur personnalisé

Étape 3 — Nom et URL MCP

Name : Merkago  ·  Remote MCP server URL : https://YOUR-DOMAIN/mcp/sse

Formulaire Name + URL MCP

Étape 4 — OAuth et autorisation

Client ID recommandé : merkago-claude-desktop  ·  Client Secret : vide. Puis Add → connexion utilisateur interne Odoo → Authorize.

OAuth Client ID + Add

Étape 5 — Whitelist (scopes)

Dans Odoo : Merkago MCP → Tokens / Scopes. Attachez uniquement les modèles autorisés pour Claude.

Sélection des scopes sur le token

Étape 6 — Créer un scope

Exemple Produits : model product.template, Read Oui, Write/Create Non au début.

Formulaire de création de scope

Parcours en 4 étapes

1. Installez le module et renseignez l’URL publique HTTPS (Merkago MCP → Configuration).

2. Ajoutez le connecteur Claude avec https://YOUR-DOMAIN/mcp/sse et autorisez (utilisateur interne).

3. Whitelistez les modèles (scopes) et gardez le Safe Mode activé.

4. Testez dans Claude : odoo_list_models puis odoo_search_read sur product.template.

Questions fréquentes

Quelle URL mettre dans Claude ?
https://VOTRE-DOMAINE/mcp/sse — HTTPS public obligatoire. Exemple : https://merkago.net/mcp/sse.
Claude peut-il modifier ma base ?
Uniquement si vous désactivez le Safe Mode et autorisez Write/Create sur les scopes. Par défaut, restez en lecture seule.
Compatible Community ?
Oui : Odoo Community & Enterprise 17, 18, 19 et 20. Dépendances : Contacts, Discuss.
OAuth Client ID ?
Recommandé : merkago-claude-desktop. Sinon laissez vide pour Dynamic Client Registration. Client Secret : toujours vide.
